# Blux Inc.‘s official website
Blux's official website based on Zola blog framework.

[Website](https://bluxlabs.com)

[Zola Theme Used](https://www.getzola.org/themes/vonge/)

# Develop

## Clone
```
$ git clone --recurse-submodules https://github.com/bluxlabs/bluxlabs.github.io
```
If you just used the plain git clone, restore dependencies using
```
$ git submodule update --init --recursive
```

## Develop Environment
With nix package manager:
```
$ nix develop
```
