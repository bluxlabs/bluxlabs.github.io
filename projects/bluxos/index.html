BluxOS

Nix-based operating system for science, trustworthy and elegant.

Our own operating system to run the software we create and to enable distributed storage of scientific research data. It leverages Nix to provide a stable and reproducible environment with a clear declarative configuration model, and includes support for AI agents to automatically generate and test system modules.
